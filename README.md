# Сайт ПРИМ – корпусная мебель на заказ

Статический сайт: главная страница, 9 страниц с советами, политика конфиденциальности. Работает на любом хостинге, сборка не нужна.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `js/config.js` | **Все настройки:** телефон, мессенджеры, ссылка на MAX, аккаунт Sketchfab, номер Яндекс Метрики, адрес для заявок |
| `index.html` | Главная |
| `sovety/*.html` | Страницы советов |
| `css/style.css` | Оформление (цвета в начале файла) |
| `img/` | Иллюстрации. Фото можно положить сюда и поменять `src` в `index.html` |

## Что заполнить перед запуском

1. **Реквизиты ООО** – в подвале каждой страницы и в `politika.html` (поиск по слову `todo`).
2. **MAX** – ссылка на профиль в `js/config.js`.
3. **Sketchfab** – имя аккаунта или список моделей в `js/config.js`.
4. **Яндекс Метрика** – номер счётчика в `js/config.js`. Цели: `zamer_click`, `form_send`, `messenger_click`, `phone_click`, `model_view`.
5. **Яндекс Вебмастер** – код подтверждения в `<head>` (там есть комментарий).

## Заявки с формы

Сейчас заявка открывается в WhatsApp с готовым текстом (Telegram и MAX – через копирование). Чтобы заявки падали в CRM, укажите вебхук Битрикс24 в `formEndpoint` в `js/config.js`.
